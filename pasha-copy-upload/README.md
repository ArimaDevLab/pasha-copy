# パシャコピー

スクショを何枚でも選ぶと、文字を読み取って1本の文章につなげるウェブアプリ（PWA）です。

- 画像と文章は端末の中だけで処理します（Tesseract.js、日本語）。
- スクロールしながら撮った複数のスクショは、重なった行を削ってつなげます。
- ホーム画面に追加すると、Androidの「共有」から直接画像を受け取れます。

## 構成

- `index.html` 画面と処理のすべて
- `sw.js` オフライン対応と、共有された画像の受け取り
- `manifest.webmanifest` アプリ名・アイコン・共有ターゲットの定義
- `ocr/` 文字認識エンジンと日本語データ（`worker.min.js` は言語データを直接渡せるよう1か所だけ修正済み）

## 公開

GitHub Pages（Settings → Pages → Branch: `main` / `/ (root)`）で公開します。
