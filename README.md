# パシャコピー

スクショを何枚でも選ぶと、文字を読み取って1本の文章につなげるウェブアプリ（PWA）です。

- 画像と文章は端末の中だけで処理します（Tesseract.js、日本語）。
- スクロールしながら撮った複数のスクショは、重なった行を削ってつなげます。
- 電話番号・メール・住所・名前・カードや口座の番号を自動で見つけて黒塗りし、全部のスクショを1つのPDF（または画像）で保存できます。隠したい言葉の指定、タップでの解除、手での追加もできます。
- 画面の端やヘッダーで切れて読み取れなかった行は、黄色で「要確認」として示します。タップで1か所ずつ、または「まとめて隠す」で一括して黒塗りにできます。厳重モードをオンにすると最初から隠します。
- 「つなげて1枚の画像で保存」で、スクロールして撮ったスクショを重なりを除いた縦長の1枚にまとめられます（黒塗りもそのまま反映）。
- PDFは黒塗り済みの画像だけでできていて、文字データや元の画像は含みません。自動検出は見落とすことがあるので、保存前に確認してください。
- ホーム画面に追加すると、Androidの「共有」から直接画像を受け取れます。

## 構成

- `index.html` 画面と処理のすべて
- `sw.js` オフライン対応と、共有された画像の受け取り
- `guide.html` 説明ページ（スクショの個人情報を安全に隠す方法と使い方）
- `manifest.webmanifest` アプリ名・アイコン・共有ターゲットの定義
- `pasha-copy-upload/` 旧アドレスからの転送用（中身は転送ページのみ）
- `ocr/` 文字認識エンジンと日本語データ（`worker.min.js` は言語データを直接渡せるよう1か所だけ修正済み）

## 公開

GitHub Pages（Settings → Pages → Branch: `main` / `/ (root)`）で公開します。
